# Inscrição para Coordenação de Curso — Motion

Animação (motion) que mostra, passo a passo, como o(a) candidato(a) faz a inscrição na **Eleição de Coordenadores de Curso** pelo Moodle da PROE/UEMS (Edital N.º 49/2026 PROE/UEMS):

1. Portal da PROE (proe.uems.br) → card **GABINETE**
2. **Acesso ao GABINETE** → aba **Eleição de Coordenadores** → **Candidatar-se**
3. Termo de Compromisso
4. Dados do Candidato
5. Requerimento em PDF e assinatura no **Portal Gov.br** (assinador.iti.br)
6. Envio do PDF assinado ao Gabinete da PROE

Os dados exibidos são fictícios. Em caso de dúvidas, encaminhe um e-mail para **proe@uems.br**.

## Publicação (GitHub Pages)

Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
O endereço fica `https://diges-uems.github.io/proe-coord/`.

Ritmo da animação: altere `const VEL = 0.7;` no `index.html` (menor = mais rápido).
